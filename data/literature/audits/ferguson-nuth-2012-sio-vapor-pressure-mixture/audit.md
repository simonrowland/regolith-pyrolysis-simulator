# Ferguson and Nuth (2012), Table 1 audit

Source: `ferguson-nuth-2012-sio-vapor-pressure-mixture`. The committed extract retains 71 Table 1 rows: 59 on PDF p. 4 and 12 on p. 5. Each row contains the printed temperature, orifice diameter, orifice area, orifice Clausing factor, mass loss, duration, mass-loss rate and uncertainty, `f`, and apparent pressure and uncertainty. The last Table 1 field is `P_m`, described by the authors as apparent measured vapor pressure; it is not treated as equilibrium pressure or total pressure.

Table 2 contains 19 printed alpha and equilibrium-pressure rows. Alpha is stored at each printed temperature. Table 2 equilibrium pressure is retained verbatim as a typed refusal because the current `p_sat` identity only represents a single condensed reservoir matching the vapor species, while this paper reports the assemblage Si(s)+SiO2(s). No SiO2 melt or single-reservoir identity is substituted. The Table 1 bundle and Table 2 pressure are unavailable quantities; the 19 alpha values migrate as `evaporation_coefficient_alpha`. The fitted values are `quoted_attributed` because the paper does not identify a row-by-row input subset that can be represented as typed lineage parents.

## Cell audit

`cell-audit.csv` lists every one of the 639 Table 1 numeric cells and all 57 Table 2 temperature, alpha and equilibrium-pressure cells retained in the extract. Each is associated with its PDF page and row and checked against both the MinerU markdown and the rendered PDF. The row and column assignments were checked on the rendered pages. No figure-derived values are included. Table 2 enthalpy values were outside the requested destinations and are not stored.

The required `mineru-compare.csv` was generated by `tools/mineru_table_draft.py compare`. It reports 59 mismatches and 50 no-matches (109 compared points). The 59 Table 1 entries are apparent-pressure cells printed with uncertainties; the converter comparison does not match those compound cell strings as a scalar value. The Table 2 blocks have MinerU block numbers 3 and 6 even though the printed caption is Table 2, so a printed-table locator of `2` yields no matching block. These compare statuses were resolved by checking the corresponding cells directly against PDF pp. 4–5 and the MinerU markdown; the cell audit records the confirmed rendered value for each stored cell. No value was altered to make the converter match.

## Migration

Isolated migration: 109 observations, 0 hard issues, 90 unavailable values (71 raw Table 1 observations plus 19 typed-refused Table 2 equilibrium pressures), and 19 migrated alpha points. Each Table 1 row reaches `temperature_K` and `orifice_diameter_m` conditions. Alpha rows reach their printed temperature. `total_pressure_Pa`, `fO2_Pa`, and melt composition remain unknown because the source does not print those experimental conditions. The measured `P_m` values are never promoted to total pressure.

Figure 2 alpha points are figure-read candidates and were not digitized; the paper's Table 2 alpha values were used instead.
