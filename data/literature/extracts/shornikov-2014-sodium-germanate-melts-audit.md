# Shornikov (2014), Na2O–GeO2: extraction audit

## Duplicate verdict

Not a duplicate of `shornikov-2014-sodium-silicate-model`. That extract is the Na2O–SiO2 model and its own scope note sets the adjacent germanate abstract aside. This PDF's citation line is Shornikov (2014), Thermodynamic properties of the Na2O–GeO2 melts, Experimental Geochemistry, vol. 2, no. 1. The running footer also says Experiment in Geosciences 2014, volume 20, number 1, page 52. Different system from the silicate paper.

## Table 1

Fifteen formation enthalpies from the simple oxides, quoted from Fan, Kozhina and Shultz, and Kohsaka. Scored as delta_fH. Ten formation entropies are context: there is no formation-entropy quantity. Five 1400 K entropy cells are dashes and are not stored.

The caption does not say whether each simple oxide is pure solid or pure liquid. Expected activity-mapper phase, if this prose were read as an activity reference: unknown. These rows are formation enthalpies, not activities.

The 600 dpi page matches MinerU and the text layer on every enthalpy and entropy digit. No enthalpy digit was hand-corrected.

## Table 2

Twenty-five ΔfG° at 1500 K, from the elements, calculated in this study. `model_derived`. The cited sources are named and their numbers are not printed, so there is no `derived_from` link (b-767). O2 = 0.000 is the printed element reference and is stored. Empty liquid cells are not stored as zero.

Provenance, stated here:

- The liquid cell prints Na4Ge9O2 next to −3625.145. The PDF text layer and the page agree. The solid cell on the same row prints Na4Ge9O20, and every Table 1 row for this compound prints Na4Ge9O20. Na4Ge9O20 is an inferred correction of a dropped final 0. The page is not claimed to print Na4Ge9O20 in the liquid cell. The value −3625.145 is the printed cell. The species key stays Na4Ge9O20 as that inferred formula.
- Liquid label MinerU `^0 GeO2` is GeO2 with a leading superscript 0, read as the standard-state mark, value −292.357.

Table 1 header prints kJ/mole. Those fifteen enthalpies are stored per mol_species.
