## Audit basis

- Printed Table 1 contains 35 runs, numbered 1–35. The 15 run-level numeric fields stored per row are shown below; the temperature and oxygen-pressure entries repeat across the printed merged cells so the migrator receives each run condition. This is 455 per-run numeric entries plus 12 unique merged T/P cells (467 physical printed numeric cells).
- Every listed numeric value was checked against the complete render of PDF page 2 (printed p. 320), evidence **(b)**. The born-digital layout page was reviewed once against its render as directed; row/column assignment was then checked across the whole table. The five composition columns are CaO, SiO2, CrOx, Cr2+, Cr3+ in that order.
- T/P merged-cell groups: runs 1–24 (1873 K, 7.04e-6 Pa); run 25 (1803 K, 1.70e-6 Pa); run 26 (1823 K, 2.57e-6 Pa); runs 27–29 (1873 K, 7.04e-6 Pa); run 30 (1923 K, 1.77e-5 Pa); runs 31–35 (1873 K, 7.04e-6 Pa).
- Machine-text conflicts resolved from the render: run 1 SiO2 is 33.4 (layout text has `33,4`); run 22 CrOx is 28.1 (layout text has `28.J`); run 35 Cr3+/Cr2+ is 12.3 (layout text has `123`). The merged-row layout around runs 5–6 was assigned by the printed No. row rules in the render.
- Each line below maps the listed cells to its printed run row and the render check (b). Mass contents remain mass percent; [Cr] remains ppm by mass; P_O2 remains Pa. No value was converted or re-referenced.
- The saturation-phase column is retained per run. Its blank cells are recorded as `liquid only` under the task's row-phase convention; the printed cell itself is blank in those rows.

## Conditions, phase, standards, and schema gaps

- Experimental text (PDF p. 1 / printed p. 319) states 20 h chemical equilibration in a molybdenum crucible, 50CO:1CO2 gas, 170 cm3/min STP, then quick withdrawal and argon quenching before chemical analysis. The activity records use the existing `quench_equilibration` method token. The source does not state that the quenched slag is glass or that its chromium valence is preserved/altered, so redox rows retain phase as quenched slag with glass status, quench preservation, and quench direction `not_stated` (page 319). Total pressure is not reported; each activity identity carries unknown total pressure. P_O2 is stored as the printed absolute pressure in Pa and reaches the activity identity as fO2_Pa.
- Activity rows represent the high-temperature liquid slag or molten Cu-Cr alloy (`l`). CrO uses the pure liquid CrO(l) standard state from Eq. (4) and the text defining s/l/g as pure-substance standard states (PDF p. 2 / printed p. 320). CrO1.5 uses the explicitly stated solid oxide standard state (printed p. 323). The Cu-Cr activity is Henrian relative to pure solid Cr(s), with gamma-zero 11.0 at 1873 K and the printed temperature dependence for other temperatures (printed p. 323); the solid endmember allotrope is unspecified.
- Typed refusals preserve the printed Cr3+/Cr2+ ratio, Cr2+/Cr3+ mass contents, [Cr] assay, L_Cr distribution ratio, and composite a_CrOx. This seat has no general Cr valence-ratio quantity/Identity.valence_basis or mass-percent/ppm quantity token; L_Cr has no quantity token; a_CrOx has no single-species reference state. No schema or migrator change was made.
- Formula-unit mole fractions for slag identity and binary Cu-Cr mole fractions are derived only to bind printed composition inputs through the existing migrator; source mass-percent and ppm cells remain unchanged. The derivation inputs are the corresponding Table 1 row records.
- Saturation phase is preserved for each run in the adjacent column. The CrO gamma values are under CrO, CrO1.5 gamma values under CrO1.5, a_Cr under Cr in Cu, and composite a_CrOx under CrOx. Figs. 2–12 are figure-read candidates only and are excluded; MinerU chart/detail hallucinations were ignored.
