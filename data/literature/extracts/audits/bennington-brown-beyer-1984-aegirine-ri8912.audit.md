# Bennington, Brown & Beyer (1984) aegirine extraction audit

## Input order and render checks

Transcription began with the MinerU Markdown/content-list HTML table blocks and the pdftotext layout text. The paper is born digital, so the text layer provides the exact characters except where the table QA flagged a digit disagreement, comma/decimal ambiguity, superscript transition marker, or OCR substitution. The relevant pages were rendered with pdftoppm and each table’s numeric grid was checked cell-by-cell for digits, sign, exponent/footnote marker, row, and column. No OCR redo was needed; the disagreements are cell-level and render-resolvable.
