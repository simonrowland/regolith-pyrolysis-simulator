# O'Hare (1972), sodium oxide formation enthalpy: extraction audit

## Source scope and method

The extract covers Part I, beginning on PDF page 2 (printed page 4513) and ending on PDF page 5 (printed page 4516). Part II begins later on the same printed page and is outside this extract. Transcription started from the MinerU machine tables and markdown, followed by `pdftotext-layout.txt`. The PDF was rendered only for the flagged temperature, table row/column assignments, table markers, and locator checks. No OCR redo was needed. No numeric fit equation with a validity range is printed in Part I, and no plot-only thermochemical values were digitized.

The paper prints two tables. Table I has nine accepted calorimetric runs; its mean row is separate. Table II has seven enthalpy-of-formation entries and a superscript-`a` footnote. `ohare-1972-na2o-formation-enthalpy.cells.csv` lists each numeric Table I and Table II cell with its physical PDF page, printed row, run column, and verification route. Table I's printed matrix is oriented with experiment numbers 1–9 as columns and measurement names as rows; each observation's `locator.record` names its experiment column, and its stored field names preserve the row labels.

## Table I: calorimetry

Printed count: nine accepted runs, six measurement rows across nine experiment columns, nine printed experiment identifiers, and four mean/uncertainty values (67 unique numeric cells total). The paper also reports ten determinations and rejects one run after moisture contaminated the sample; no numeric result is printed for that run. Every Table I body cell and the merged mean cell was checked against the PDF page 3 render (route b). The QA table candidate had 73 values, only 0.187 digit agreement, and flags `latex=10;numeric_mismatch=70`; the row/column assignment issue was resolved by the render rather than accepted from the draft. The render confirms all nine columns, signs, precision, ΔHvap corrections, and markers `b`, `c`, and `d`.

The run phase is Na2O(c), stored with phase token `cr` and printed phase `c`. Each run uses the printed mean reaction temperature 25.0°C (Table I footnote b) and the calorimeter's printed 0.1M NaOH solution. `T_C` retains the source temperature; isolated migration carries its normalized 298.15 K value through `point_conditions.temperature_K`. The table reports the mass, Δtc, calorimeter energy equivalent, heat term, ΔHvap correction, and ΔH/M for every run. The mean values are `−3858.16 ± 1.59 J g−1` and `−922.12 ± 0.38 cal g−1`; the uncertainty is the standard deviation of the mean (footnote d), with no confidence level stated.

Each of the nine calorimetric runs, the mean, and reaction (1)'s derived molar enthalpy remain typed-refused because the exact specific solution/reaction enthalpy quantity is absent from `simulator/battery/enums.py::Quantity`, `simulator/battery/migrate.py::QUANTITY_ALIASES`, and `simulator/battery/migrate.py::TYPE_QUANTITY`. The exact printed values and units remain in the source extract; no `delta_fH` near-match is used for reaction enthalpy.

## Table II: formation values and markers

Printed count: seven rows and seven numeric values. MinerU and pdftotext agree on all seven values (route a); the page 4 render checks row association and the marker cells (route b), including the caption's superscript `a` and row markers `11`, `8a`, `8b`, `9`, `10`, `5`, and no marker for “This work.” The render resolves pdftotext's `Forerand` as `Forcrand`. The footnote is retained exactly: `Results from Refs. 8–11 taken directly from JANAF.21a`.

Table II does not print a phase for each entry. The seven values, investigator strings, reference markers, caption marker, and footnote therefore remain a located context table rather than observations with an invented phase. “This work” repeats the main `−99.14 kcal mole−1` value, so it is preserved as the printed table occurrence without a second observation.

## Schema, conditions, and evidence

- `simulator/battery/enums.py::Quantity` has no exact reaction-enthalpy, specific solution-calorimetry, atomization-enthalpy, sublimation-enthalpy, or mean bond-enthalpy quantity. `simulator/battery/migrate.py::QUANTITY_ALIASES` has no exact aliases for these, and `simulator/battery/migrate.py::TYPE_QUANTITY` has no reaction-enthalpy fallback. The closed host set is `tools/validate_literature_extracts.py::OBSERVATION_TYPES`; `heat_capacity_and_heat_content_series` is used only to carry the typed refusals. These observations use explicit descriptive non-token quantities and `status: typed_refusal`.
- Existing reaction-enthalpy extracts, including `kroger-kreitlow-1956-soda-lime-silicate.yaml`, also preserve unsupported reaction heats as typed refusals; their descriptive labels do not add an exact token to the current closed sets.
- The exact quantity for H2O(l), Na2O(c), and Na2O(g) formation enthalpies is represented by `delta_fH`, so those three outputs migrate as numeric points. The Table II historical phase is omitted because Table II does not specify it per row.
- Every Table I run, the mean, reactions (1)–(3), reaction (7), and atomization row has a source temperature when one is stated. The Gross–Wilson reaction datum has no printed temperature. No calorimeter total pressure or fO2 is printed. The high-vacuum condition belongs to sample treatment and is not copied onto calorimeter runs. The isolated-migration test asserts pressure and fO2 are absent.
- The own Table I runs are `measured_direct`; their mean and reaction (1) reduction are `measured_reduced`. O'Hare's formation result is `measured_reduced` from the printed reaction cycle. The Parker/Gunn and CODATA inputs remain attributed. The gas formation result is a measured-reduced derivation from O'Hare's solid result and the attributed sublimation input. No evidence class is changed to avoid a gate.
