# Itoh et al. (1988) extraction audit

## Coverage and transcription

The extract records every numeric Table I measurement row and all numeric body cells in Table II, plus the four printed temperature fits (Equations 3, 4, 7, and 8). Table I has 55 data rows: 36 in Run 1 and 19 in Run 2. It contains 55 EMF values, 55 author-calculated exchange Gibbs values, and 34 printed Na2S standard Gibbs values. The dagger column has 21 blank cells; none was imputed. Table II has three body rows at 500, 600, and 700 K and 21 thermochemical values across its seven quantity columns.

The full cell audit is in `itoh-1988-na2s-beta-alumina-emf.audit-cells.csv`: 278 numeric table cells (Table I row number, temperature, EMF, ΔG*, 34 dagger values, and all 24 Table II cells) plus four located equation-form records. Every Table I and Table II numeric cell is identical in the MinerU draft and pdftotext transcription. Numeric agreement was 1.000 for both tables. The 600 dpi render of PDF page 2 (journal p. 1396) confirmed the complete row/column assignment and signs in both tables and the Table I footnotes. The equation symbols, coefficients, uncertainty widths, and fit ranges for Equations 3, 4, and 7 were checked against that render; Equation 8 was checked against a 600 dpi render of PDF page 3 (journal p. 1397). No OCR redo was needed.

The compare-only mapping is `itoh-1988-na2s-beta-alumina-emf.mapping.yaml`. The direct compare output is `itoh-1988-na2s-beta-alumina-emf.compare.csv`: 117 matched, 48 marked mismatch, 0 no-match, and 0 locator errors across 165 numeric observation values. All 48 flags are caused by `tools/mineru_table_draft.py::_phase_matches_column`: the tool accepts `solid`, `liquid`, or `gas` and maps `cr` to `solid`, but does not recognize the canonical phase tokens `l` and `g` required by the extract-to-battery migrator. They occur on the 21 Table I high-temperature rows marked `l` (42 value cells) and the Table II `S2(g)` / `Na(l)` reference columns (6 cells). Their row and column assignments and values were resolved against the render and are individually listed in the full cell audit. The companion `itoh-1988-na2s-beta-alumina-emf.compare-phase-filter-compatible.csv` was generated by running the same compare on a scratch copy in which only those phase tokens were expressed as `liquid` / `gas`; no values or locators changed. It matched all 165 values with no mismatch, no missing candidate, and no locator error. The stored extract retains the canonical `l` / `g` tokens. Table locators use the printed labels `I` and `II`, PDF page 2, and the printed row identity. The separate draft row/column indices support tool comparison.

## Cell and experimental conditions

The cell is printed as `Na(l)|β″-alumina|Na2S + Ag2S + Ag`; the working electrode mixture contains Ag, Ag2S, and Na2S, with liquid sodium as the 3N reference electrode (3×10−3 kg). The electrolyte is a β″-alumina crucible. The prepared powder ratios are 1.00:1.00:1.00 for Run 1 and 3.00:3.00:1.00 for Run 2. Those initial charge ratios remain in experiment context. Point conditions carry the printed Run 1 mol inventory through No. 33, where it is still the reported charge basis, and each row's T(K). After Run 1 No. 33 the authors titrated 300 C of sodium into the cathode before Nos. 34–36; those rows have unknown composition because the resulting mixture is not quantified. Run 2 has unknown row-level composition because the authors report Na–Ag ion exchange above 738 K but no post-exchange ratios. The initial ratios are also preserved on each raw EMF row as printed sample context, not promoted to a changed equilibrium melt composition.

The source reports evacuation at 373 K for 80 ksec followed by purified argon, but no measurement total pressure, argon ratio, or oxygen fugacity. The extract records both total pressure and fO2 as unknown on every data and fit observation. The paper estimates an Ag2S–Na2S eutectic at 738 ± 5 K and reports a liquid sulphide phase above 738 K; the cell rows are assigned `cr` at or below 738 K and `l` above 738 K. Equation 8's fit temperature interval and every other fit interval are retained in located `point_conditions.temperature_K` records.

## Numeric audit and fit forms

Table I's starred column is retained exactly as printed and as explained in its footnote, `ΔG = −FE` with `F = 96484.56 C mol−1`. Its author-calculated values are linked to their row's EMF. The 34 dagger values are also linked to the row EMF, the adjacent starred value, and the stored Table II Ag2S standard formation-Gibbs reference rows. The Results text and Equation 2 explicitly say that ΔG°(Na2S) was calculated from experimental EMFs and Table II ΔG°(Ag2S) values. The Table I dagger footnote instead names a ΔG°(Na2S) value from Table II. This wording conflict is retained and recorded; no values were recomputed.

All Table II numeric cells are stored. The five G(T) columns for S2(g), Na(l), Ag(s), Na2S(s), and α-Ag2S(s) use the descriptive non-token quantity `standard_gibbs_energy_as_published` and remain typed refusals. `simulator/battery/enums.py::Quantity` has `DELTA_FG` for formation Gibbs energy but no generic G(T) quantity, and `simulator/battery/migrate.py::QUANTITY_ALIASES` has no exact alias. The two ΔG° formation columns use `delta_fG` and are attributed to references [3, 4] as cited in Table II. The paper reports ±1150 J mol−1 for ΔG°(Ag2S) and a maximum ±5700 J mol−1 for the Table II ΔG°(Na2S) values between 500 and 700 K; confidence level is not stated.

The extract stores the printed fit forms without making additional calculations:

The p. 1397 prose gives Run 2 No. 15 as 1.4395 V, while Table I prints 1.4396 V; the extract stores the Table I value.

- Equation 3: `E/V(±0.00057) = 1.75793(±0.00086) − 4.452(±0.014) × 10⁻⁴(T)`, for `463.4 < T < 737.7 K`; its 33 stored EMF points are the fit inputs.
- Equation 4: `ΔG (J ± 55) = −169613(±83) + 42.95(±0.13)(T)`, derived from Equation 3 over the same interval. Its uncertainty widths are printed; confidence level is not stated.
- Equation 7: `ΔG°_Na2S (J mol−1 ± 130) = −427940(±200) + 124.92(±0.32)(T)`, for `463.4 < T < 737.7 K`; its 33 stored dagger values strictly below 737.7 K are the fit inputs. The discussion reports an overall ±1160 J mol−1 uncertainty after combining the fit and Ag2S-reference uncertainty; confidence level is not stated.
- Equation 8: `ΔG°_Na2S (J mol−1) = −441729 + 145.44(T)`, for `500 < T < 700 K`; it is `model_derived` from the three stored quoted-attributed Table II ΔG°(Na2S) values. The source reports a maximum uncertainty of ±5700 J mol−1 over that interval; confidence level is not stated.

EMF and exchange-reaction Gibbs values have no exact quantity token. They are stored with explicit non-token labels and typed refusals: `simulator/battery/enums.py::Quantity` and `simulator/battery/migrate.py::QUANTITY_ALIASES` do not define those quantities, and `tools/validate_literature_extracts.py::OBSERVATION_TYPES` has no EMF-specific type. Explicit labels prevent `simulator/battery/migrate.py::TYPE_QUANTITY` from inferring formation Gibbs energy. The Table II G(T) values use the same typed-refusal treatment because no exact token represents generic G(T). The fitted functions are retained as typed-refused forms rather than represented as point values. Figures 1 and 2 are figure-read candidates and were not digitized.

## Isolated migration

The real migrator produced 169 observations with 0 hard issues. It produced 40 point values (34 Table I ΔG°(Na2S) values and six Table II formation-Gibbs values) and 129 unavailable values. The exact quantity-unknown set is the 55 EMF observations, 55 exchange-Gibbs observations, 15 Table II generic G(T) observations, and the Equation 3 and 4 fit records. Equations 7 and 8 retain the exact `delta_fG` quantity but their function forms are unavailable as point values. Every observation has a known migrated phase; each data point and fit carries a located temperature condition. Run 1 Nos. 1–33 carry the printed initial mol inventory in point conditions; Run 1 Nos. 34–36 and all Run 2 rows carry unknown current composition, while the original run ratios remain in the experiment and EMF value context. The source extract records total pressure and fO2 as unknown; the migrator drops the unprinted total-pressure condition and preserves unknown fO2, and neither identity axis contains an invented value.
