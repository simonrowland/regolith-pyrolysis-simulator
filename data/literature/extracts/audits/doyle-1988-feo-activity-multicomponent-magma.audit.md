# Doyle 1988 FeO activity extraction audit

Table 1A contains 129 activity/composition rows: Fig. 2A 30, Fig. 2B 33, Fig. 2C 38, and Fig. 2D 28. This agrees with the paper's abstract. Its 744 numeric cells comprise 129 activities and the printed oxide compositions. Of these, 42 MinerU/pdftotext disagreements and five footnote-marked activity cells were checked against the 600 dpi page 4 render; the remaining 697 numeric cells agree in both machine reads. Table 1A's row and column assignment was checked against the render. The cell-level methods and coordinates are in the companion `.cells.csv`.

Table 1B has eight setpoint rows. Its 48 numeric cells (activity, uncertainty, -log10 fO2, and gas-flow values) were checked against the 600 dpi page 5 render because MinerU did not emit a table block. The eight dashes in gas-flow cells are typed absent in the extract. Table 1B gives `-log10 fO2` to two decimals but states no bar/atm reference. The controller ruling allows the migrator's bar default at this precision: bar/atm differs by 0.0057 dex, below the 0.01 dex printed resolution. Each raw printed value and the signed condition are retained.

The table comparison reports 124 direct matches, five mismatches, one no-match, and 274 unverifiable locator checks. The five mismatches are the footnote-marked Table 1A activity cells listed as render-verified in the companion mapping; their rendered numeric values match the extract. The no-match is the quoted prose value `aFeO = 1.93` on page 2, checked on the page render; it is not in the MinerU table draft. The 274 unverifiable locator checks are Table 1B `1B` labels absent from the MinerU index. They cover the 129 row fO2 locators, 129 activity-uncertainty locators, eight setpoint context locators, and eight typed dash locators. The printed page 5 table and all its numeric cells were checked on the render. The raw compare output is in the companion `.compare.csv`.

Migration yields 130 numeric observations (129 Table 1A rows and the quoted 1.93 value), zero unavailable observations, and zero hard issues. There are no numerical activity coefficients or EMF readings. The paper prints `gamma_FeO = a_FeO/X_FeO` as a relation only. Table 1A compositions are quenched glasses, but the article does not claim that FeO activity was preserved on quench; the scored activity phase is the high-temperature liquid. Figure 2–6 plotted values remain figure-only and undigitised.

The source standard state is `molten Fe0.947O (COUGHLIN, 1954)`. Preserve it verbatim: `simulator/battery/enums.py::ReferenceStateConvention` has no exact token for this nonstoichiometric liquid, so the migrated identity reference state remains unknown. The separately quoted 1.93 value retains its own stoichiometric liquid FeO attribution and 1380±5 °C statement. The printed dashes in Fig. 2A K2O cells are absent, not zero.
