## Evidence and schema decisions

- Table 2's two isotope-delta cells per element retain the original citations printed in the reference column. The table's MDF is author-calculated and is not admitted as a measurement. The chd/CI abundance and isotope identifiers are retained as supporting printed fields. The quoted delta rows are typed refusals because whole-chondrule isotope deltas lack an evaporation identity; their source values and stated 2σ widths remain preserved.
- Table 3 gives group averages from the authors' mesostasis compilation, normalized to Lodders (2003); it is source-attributed aggregate composition evidence. `ci_normalized_alkali_ratios` has no schema token, so values remain typed-refused. No per-group temperature, pressure, oxygen fugacity, or full composition is printed; none is supplied.
- Table A.4 optical basicity values are attributed to Mathieu (2009); `optical_basicity` has no schema token and is typed-refused.
- Table A.5 values are calculated by Jacquet et al. from Mathieu (2009) Table V.5 experimental slopes through Eq. (A.3). Since the inputs aren't stored here, the value class is `quoted_attributed` (d-110). The source prints 1400 °C and NNO at fO2=2.11×10^-6. It does not print total experimental pressure or a full melt composition for each Lambda; no pressure or composition is invented. The Lambda-only rows cannot satisfy the activity-coefficient composition identity, so they are typed-refused.
- Table B.6 is model context: its caption says the listed recondensation temperatures are calculated for typical activity coefficients. No output is extracted. Table 1 is symbols only. Figure-read candidates are Figures 2–8 and 10–12 for plotted Na/Al, K/Al, compositions, and model trends; values were not digitized.

The isolated real migration emitted 32 observations, 32 unavailable values, 0 registry issues, and 43 validation issues. All 43 are `identity_incomplete` on typed-refused rows: Table 2 has 14 isotope-delta points without temperature and subtype (28 issues); Table A.5 has five points missing full composition, total pressure, and mapped `fO2_Pa` (15 issues). Table A.5's printed `fO2 = 2.11×10^-6` is retained with NNO in its original dimensionless form. There is no schema path for this non-log form, so it remains a documented schema gap; it is not converted into an unprinted log or pressure. The printed 1400 °C does bind to each A.5 identity as 1673.15 K. Table A.5 composition is unknown because only Lambda is printed; total pressure is unknown because it is not stated. The unsupported Table A.4 and Table 3 quantities are admitted as typed refusals with their cell values preserved.

`mineru_table_draft.py compare` reports 0 locator errors after correcting the generated draft's Appendix caption evidence to its printed A.4/A.5 labels. It matches all 8 A.4 basicity cells. Its 24 mismatches are the 14 Table 2 isotope values, five Table 3 means, and five A.5 coefficients: these appear in value±uncertainty cells or LaTeX exponents which the comparator does not split. Each was checked against the rendered page (27, 34, or 37) and agrees. The per-cell matches and render resolutions are enumerated above; the committed compare CSV preserves every result.
