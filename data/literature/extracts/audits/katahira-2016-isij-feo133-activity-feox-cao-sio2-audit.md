# Katahira & Hayashi (2016) extraction audit

The extract contains all 47 printed activity rows: Table 1(a) 8, Table 1(b) 5, Table 2(a) 8, Table 2(b) 6, Table 3(a) 13, Table 3(b) 7. The six MinerU table drafts each have 100% digit agreement with pdftotext. Render checks on PDF pages 2, 3, and 4 verified the temperature and method text, the Pt crucible description, and the table row/column assignments. Every activity and numeric table cell retained in the extract is listed in the accompanying TSV; table values use the two matching machine reads (audit method a), with page renders verifying layout. The 1573 ± 2 K condition and apparatus facts were checked on the page 2 render (method b).

The table activity is printed as log10(a_FeO1.33), relative to solid FeO1.33; FeOx composition is treated as FeO per the source statement on published page 1167. Every row has its own printed P_O2 and liquidus-phase composition. fO2_Pa is only the exact atm-to-Pa normalization of that printed P_O2. Total pressure remains unknown: 50 ml/min is a gas flow, not a pressure. The paper mentions a Mössbauer Fe2+/Fe3+ ratio only for a homogeneous standard sample; it provides no Fe3+/Fe2+ values for these activity rows. Figures 3-9 contain figure-read candidates and were not transcribed.
