# QMS calibration observation contract

## TL;DR

Use the existing observation quantities to distinguish **author-calibrated partial pressure** (`p_partial`) from **ion signal** (`ion_intensity` / `ion_intensity_ratio`). Keep calibration provenance with the experiment apparatus record that the KEMS scorer already reads. For an ion signal, compare shape only after normalizing both the published trace and the kernel partial-pressure trace to the same declared, nonzero point or source-declared baseline. Never derive pressure or flux from ion current in this contract, and never run an author calibration over a pressure the author already reported.

The contract makes a QMS observation auditable and comparable; it does not create source data. Gooding & Muenow has no local extract or PDF, the Zaitsev/Stolyarova records are largely equilibrium/activity evidence rather than time traces, and Sauerborn's held O₂ row is a baseline-normalized sparse figure digitization. Those limits remain explicit below.

## Existing scorer boundary

- `simulator/battery/score.py::_has_ungrounded_kems_partial_pressure_calibration` gates KEMS `p_partial` using `experiment.apparatus.calibration`. `simulator/battery/validity.py::_calibration_grounded` requires each calibration entry to be source-located and explicit. A separate `pressure_calibration_standard` observation does not by itself populate that apparatus calibration record.
- `Quantity.ION_INTENSITY` and `Quantity.ION_INTENSITY_RATIO` already exist, and `score_metrics.py` assigns them relative and dex metrics. `score.py` excludes both from vapor quantities. The missing contract is the QMS provenance, same-channel anchor normalization for a time series, and a time-series comparator; it is not a new ion-current-to-flux rule.
- `simulator/diagnostic_helpers/kems.py` has a diagnostic case calibration with `standard`, `method`, `sensitivity_factor`, units, and source locator. Reuse those meanings; do not add a second calibration vocabulary or move rule logic into that helper.

## Observation fields and the failure each prevents

Calibration belongs to the existing experiment apparatus record because the instrument setup is shared by that run and the scorer already reads it there. Keep entries scoped to the measured ion/channel when sensitivity or corrections differ by ion. The observation continues to hold its measured quantity, source locator, point conditions, and time-series points. Do not copy calibration values onto each point.

| Field | Required representation | Failure prevented |
|---|---|---|
| Calibration standard | Source-named standard(s), the ion/channel they calibrate where stated, method, and source locator. Unknown/not reported stays typed unknown. | A reported pressure is treated as absolute without evidence, or one calibrant is silently applied to a different ion. De Maria's silver and O/O₂ paths show that one run can have more than one standard. |
| Instrument/sensitivity factor | Author's factor and units, with its channel scope and locator; do not derive a default factor. | A factor of one or an unreported response is silently assumed, or a factor is used with the wrong units/channel. |
| Ionization cross-section source | Named source and applicability to the ion/electron-energy range, with locator; record “included in author factor” when that is what the paper says. Do not calculate a new cross-section here. | A guessed or mismatched cross-section turns current into a false absolute pressure, or a cross-section already folded into the author factor is applied twice. |
| Fragment correction | Typed state: applied (with the author's mapping/factor and locator), not needed (with source basis), or unknown/not reported. Preserve the values as published; never apply the author's correction again. | A fragment peak is counted as a separate gas species, or an undocumented/double correction is applied. Unknown does not mean zero correction. |
| Relative-series anchor | A declared positive point from the same channel/run, or an explicitly source-declared common baseline normalization with its value and locator. No fitted scale. | Raw count magnitude is compared as an absolute pressure, or a convenient point from another run is silently used to set scale. |
| Time base | For a time series: coordinate unit, zero event/reference, source locator, and the existing per-point elapsed-time coordinate. Keep per-point T only when reported. | Clock time, heating time, and time since a QMS reference are conflated; the model is aligned at the wrong event or a missing T(t) is invented. |
| Onset/detection threshold | Source-reported threshold/definition and locator; otherwise typed unknown and onset is unavailable. Reuse an existing detection-limit field when present. | A scoring threshold is chosen after seeing the model residual, creating an arbitrary onset T/t. |

All numeric/source claims above remain source-located. Missing or ambiguous calibration is a typed unknown/refusal for an absolute-pressure claim, never a normal calibration value. A relative trace can still be scored if its same-channel shape, anchor, and time base are explicit; it does not need an absolute sensitivity factor.

## Quantity and calibration rules

1. **Published calibrated pressure:** retain the source value as `p_partial` in pressure units. The author's ionization calibration is already embodied in that value. The scorer compares it directly with a model partial pressure at the same physical boundary and conditions. Calibration metadata grounds the evidence; it never transforms either the reported pressure or the model output. This is the no-double-calibration rule.
2. **Published ion current/intensity:** retain it as `ion_intensity` (or the existing `ion_intensity_ratio` when the paper reports a ratio). It is an instrument signal. For shape-only comparison, declare one positive anchor point from the same ion/channel and run, or use the source's explicit common baseline normalization for that trace; then compare `I(t)/I(anchor)` with `p_model(t)/p_model(anchor)`. Apply no fitted scale and no absolute calibration factor. A constant sensitivity cancels; if the instrument response is reported to drift/change during the trace, refuse shape scoring. If the anchor, channel identity, or stable time base is missing, return a typed unavailable/refusal.
3. **Cross-channel ratios:** a ratio between different ions is not a single-species partial-pressure ratio. It needs both channel calibrations and the author's stated ratio method; otherwise retain the ion-current-ratio quantity and do not compare it as partial pressure.
4. **Never current-to-flux:** ion current is not molar flux. Neither a sensitivity factor nor a cross-section supplies the missing effusion/transport geometry. Flux comparison requires an independently typed flux observation and a physical flux model; this QMS contract does not add that conversion.
5. **d-122 boundary:** source-reduced oxygen calculated from the run's own ion currents is an imposed, typed `measured_reduced` input. Preserve that source result as given. Do not recalibrate its component currents, infer a new oxygen flux from them, or use the QMS comparator to overwrite it.

The contract does not add a separate `calibration_applied` switch: quantity semantics already decide it. `p_partial` means compare the calibrated pressure as stored; `ion_intensity` means shape-only after anchor normalization. A switch would duplicate that decision and create contradictory states.

## Time-series comparator

Compare only when the kernel emits the same physical observable at the same measurement boundary and can be sampled at the published elapsed times. A KEMS cell pressure is not automatically a process-chamber pressure. Do not substitute a flux, cumulative mass, or temperature envelope for QMS pressure.

- **Per-point residual:** for calibrated pressure, `log10(p_model / p_observed)` in dex. For a relative ion trace, `log10((p_model(t)/p_model(anchor)) / (I_observed(t)/I_observed(anchor)))` in dex. Keep the point's reported uncertainty/digitization band alongside its residual. A missing or nonpositive datum/anchor refuses; it is not silently dropped or replaced by zero.
- **Integral:** sample the model at the observed elapsed-time points and use composite trapezoidal integration over only the first-to-last observed interval for both series; do not extrapolate. Calibrated pressure integrates to pressure×time; normalized signal integrates to dimensionless×time. Neither integral is evolved mass or flux. Do not report an integral from sparse, cross-run anchors as if they were one continuous trace.
- **Onset:** compare the first crossing of a source-declared detection/onset threshold, then report elapsed-time residual and, only when T is reported at the crossing, temperature residual. Use the same threshold on the model series. If no threshold or no pointwise T(t) exists, onset T is unavailable; do not infer it from a T range or time axis.
- **Static KEMS p(T):** score pointwise pressure against the equilibrium/effusion prediction at each published T. It has no time integral or time onset unless the source supplies a true time coordinate.

This yields three separately inspectable outputs—point residuals, a same-observable integral, and threshold onset—without making instrument signal stand in for material transport.

## Implementation chunks and mechanical proofs

Each chunk is one concern, sequenced by dependency. This document is design-only; none of the following was implemented or tested in this change.

1. **Extend the existing experiment apparatus calibration record for QMS provenance.** Add source-located, channel-scoped standard, factor+units, cross-section source, and fragment-correction states to the existing owner; keep unknown/not-reported typed and avoid a parallel observation-level calibration copy. Reuse the diagnostic KEMS calibration vocabulary. **Proof:** migration/round-trip assertions for the De Maria calibration record show each field retains its printed value, locator, and channel scope; deleting a required locator makes the absolute calibration ungrounded, while a typed unknown does not become a value.
2. **Bind author-calibrated KEMS pressure without applying calibration again.** Make the existing `p_partial` KEMS gate consume the linked apparatus record; keep the author pressure untouched. **Proof:** migrated De Maria and Costa pressure points equal their published values before and after metadata binding; a mutation that multiplies/divides either stored pressure by its sensitivity/cross-section factor fails. A current-only row cannot enter the pressure comparator or a flux rail.
3. **Add declared-anchor shape residuals for existing ion-intensity quantities.** Extend the existing battery series/metric owner to normalize same-channel `ion_intensity` and kernel partial pressure to the declared point or source-baseline anchor; retain the existing time coordinate's unit, zero event, locator, and per-point T only where printed. Do not add a new quantity or scale fit. **Proof:** Costa's selected measured-current series (once its event/time zero is confirmed) yields same-point residuals; a complete Sauerborn curve does too after its full trace is digitized. Multiplying every observed current by a constant leaves normalized residuals unchanged, while removing the anchor or mixing channels refuses. A changed/missing clock zero refuses alignment. Verify the emitted units are relative/dex, never flux.
4. **Add the integral result for an eligible aligned series.** Use model values at observed times and composite trapezoidal integration only over the first-to-last observed interval; do not extrapolate. **Proof:** an independently calculated reference series gives the same point-grid integral; changing elapsed-time units from seconds to minutes changes the integral by 60×. Calibrated pressure reports pressure×time, normalized signal reports dimensionless×time, and neither is labelled mass or flux. Sparse points from separate runs cannot be combined.
5. **Add threshold onset results for an eligible aligned series.** Require a source-declared detection/onset threshold and apply it to both series. Report elapsed-time onset and report onset T only where pointwise T is printed. **Proof:** a source-backed threshold crossing reproduces its time; removing the threshold makes onset unavailable, while removing pointwise T removes only onset-T. No onset is inferred from a T range or an elapsed-time axis.

## Scope decision

No flux field, ion-current-to-flux equation, adjustable fit factor, inferred calibration default, or separate calibration registry is justified. The calibration metadata prevents false absolute pressure and double calibration; the anchor prevents arbitrary scale fitting; the time base prevents false alignment; the fragment state prevents species misassignment. If the primary source does not state a value, preserve the typed unknown and the observation's honest quantity.
