# Reference PDFs

`data/literature/extracts/SCHEMA.md` is authoritative: **`source_id` is the
extract filename stem**. One extract file is one literature source.

```text
docs/references/pdfs/<NN-topic>/<source_id>.pdf
docs/references/pdfs/<NN-topic>/<source_id>.md      # sibling sidecar
data/literature/extracts/<source_id>.yaml           # measurement extract
```

SCHEMA example: extract `data/literature/extracts/costa-jacobson-2015.yaml`
declares `source_id: costa-jacobson-2015`. The PDF and sidecar stems match that
id when a copy is filed here.

## Choosing a new source_id

- **KEMS / Langmuir measurement papers:** take the next `kems-NNN-author-year`
  id from the inventory (`data/literature/INDEX.yaml` and this tree under
  `99-kems-langmuir/`). Example: `kems-001-homma-1966`.
- **Other topics:** `author-year` kebab, as in the SCHEMA example
  `costa-jacobson-2015`.
- **Preset ids** (snake_case such as `halwax_sergeev_mueller_schenk_2024` or
  `sesko_2024`) are **aliases** of a canonical extract `source_id`. They are
  never index rows.

Existing kems-prefixed vs bibliographic kebab vs preset snake_case names for
the same DOI or report number are listed in `data/literature/INDEX.yaml` as
alias groups that need owner/controller resolution. The builder does not pick
a winner.

## Sidecar fields (required)

Each sibling `<source_id>.md` records:

- citation
- DOI (or report number when no DOI exists)
- license / OA basis
- sha256 of the PDF
- retrieved date (ISO `YYYY-MM-DD`)
- retrieval URL

## What belongs where

- `NN-<topic>/` is a numbered topic directory (`99-kems-langmuir`,
  `02-thermochemistry`, …).
- A PDF of a **measurement paper** supports an extract under
  `data/literature/extracts/`. The engine is validated against extracts.
- A PDF of an **assessed compilation** supports `data/literature/compilations/`
  and must not be turned into a scoring extract. See
  `data/literature/compilations/README.md`.
- Filing a PDF before its extract exists is allowed. The gap is tracked in
  `data/literature/INDEX.md`.

When a source later receives a `REF-NNN` row in `docs/references/references.yaml`,
keep the `source_id` stem; do not rename away from the extract identity.

The tracked map of PDFs, extracts, aliases, battery consumers, and hunt ids is
`data/literature/INDEX.yaml`, generated by `data/literature/build_index.py`.
