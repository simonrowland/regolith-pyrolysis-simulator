# IMCC SF-04 implementation retired

**Status:** RETIRED, 2026-09-30. This historical specification no longer describes
the simulator's implementation. The maintained IMCC implementation and data packs
live in [openimcc](https://github.com/simonrowland/openimcc), pinned in
`pyproject.toml` (the `imcc` extra).

in the simulator's source catalog. They document scientific provenance, not a
second implementation.
