# S7 — notice / flag / authority dropped in transit

**Repo tip (write branch):** `1174258a2` (`empirical/reviews-2026-09-22`).  
**Code base audited:** `origin/review/janaf-batch-2026-09-22` (`a49cef012`). READ-ONLY; no product edits.  
**Scope:** whole repo (engine adapters → bridges / providers / battery runner / score serializers). Vapour-rail–only drop sites are tabulated in `ferry/sweeps/S7b-vapour-bridge-notices.md` and cross-referenced below (not double-counted).  
**Predicate:** an engine/adapter attaches a notice, warning, authority level, domain flag, or refusal reason, and an intermediary (bridge, provider, cache, runner, serializer, merge) discards it, so the consumer sees an **unflagged** value.  
**Project doctrine:** predict-and-flag — flagged values must stay flagged to the ledger.  
**Seed:** VapoRock commissioning notice dropped by vapour bridge and shadow provider; battery runner drops notices for every engine.

**Attachment corpus note:** On audited tip `a49cef012`, AlphaMELTS / ThermoEngine already stamp `diagnostics.{commissioning_notice,authority,certified_band}` + `CommissioningNotice: …` warnings via `_apply_engine_commissioning`. VapoRock’s matching stamp lands on `origin/review/t959-vaporock-notice` (`ce8d6a7f6`); on `a49cef012` VapoRock still attaches other domain flags (`pressure_control_authoritative`, projection / empty-speciation diagnostics, pressure-authority warnings) that the same intermediaries discard. Bridge / shadow / battery harvest paths have **no** forward slot for commissioning keys today — so the seed drop is live in the intermediary, and consequential for AM/TE now and for VR commissioning as soon as t959 merges.
