## No-hit areas (audited; not counted)

- **`simulator/battery/migrate.py` `_dec_str` for true `Decimal` inputs:** format-`f` + strip trailing zeros preserves exact Decimal; float / transcendental-power branches are the defects (counted above).  
- **`simulator/battery/records.py` `as_decimal`:** documents float→`Decimal(str(x))` as printed form; safe for clean literals, unsafe when `x` already carries binary pollution (enabler for sites 1–2, not a separate store write).  
- **PyYAML `safe_dump`/`safe_load` float round-trip:** probed; float64 values round-trip identically for ordinary thermo constants — extra loss appears only when code **pre-formats** (`:.10g`) or **pre-pollutes** via float / non-integer Decimal.**.  
- **`json.dumps` / results-store `_jsonable`:** passes finite floats through without extra digit clipping; canonical path quantizes only for digests (counted).  
- **`tools/compose_vapour_rail_carriers.py`:** explicitly avoids round-tripping the catalog through `yaml.safe_dump`; new rows use high-precision text splice — defensive, not a hit.  
- **AlphaMELTS melts-file `:.6f` after binary32 quantize:** documented engine contract, not silent store loss.  
- **Preset runner `hours = int(duration_h)`:** refuses non-integer with `math.isclose` — safe contrast to `recipe.py`.  
- **Species-rail / Gibbs `write_ledger`:** dumps float residuals via `yaml.safe_dump` without extra `round`/`:.Ng` gate (float64 thermo residual is the native type).  
- **`int()` on hour counters** (runner hours, melt.hour snapshots): discrete time indices, not measured continuous quantities under this predicate.
